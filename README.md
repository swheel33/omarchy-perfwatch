# omarchy-perfwatch

An Omarchy shell plugin for recording and reviewing historical system
performance incidents without duplicating live monitors such as btop.

## Planned scope

- A native QML bar widget and compact Omarchy-styled popup.
- A lightweight collector that runs only while Omarchy Shell is active.
- Detection of sustained CPU, memory, swap, and I/O pressure.
- Bounded historical incident records with surrounding diagnostic context.
- Local state stored under the user's XDG state directory.

The planned plugin ID is `swheel33.perfwatch`.
